# SENAC HC: Complementary Hours Management 🎓

A complete ecosystem for managing and validating complementary hours for undergraduate students. Developed as a Capstone Project (Projeto Integrador) for the Systems Analysis and Development Program at Senac College.

**License:** Senac
**Compliance:** LGPD

---

# Project Overview 📋

**SENAC HC** is a digital ecosystem designed to simplify the submission, validation, and monitoring of complementary hours.

The project consists of three integrated applications: a Backend API, a Web Platform, and a Mobile Application. Together, they provide a complete environment where students can submit certificates, track their progress, and receive feedback, while coordinators and administrators can validate activities and manage academic requirements.

Unlike traditional manual processes, SENAC HC centralizes all information in a single platform, reducing paperwork, increasing transparency, and improving communication between students and academic staff.

---

# Key Features 🚀

* **Certificate Management:** Students can upload certificates and monitor validation progress in real time.
* **Coordinator Validation Dashboard:** Coordinators can review, approve, or reject submitted activities and register validated hours.
* **Mobile Accessibility:** Students can manage complementary hours directly from their smartphones.
* **OCR Integration:** Automatic extraction of information from PDF and image certificates.
* **Role-Based Access Control:** Different permissions for students, coordinators, and administrators.
* **Email Notifications:** Automated notifications for password recovery and system events.

# System Workflow ⚙️

Students submit certificates through the Web or Mobile applications.

The Backend API processes requests, validates business rules, stores information securely, and manages authentication.

Coordinators review certificates, approve or reject requests, and validated hours are automatically reflected on student dashboards.
